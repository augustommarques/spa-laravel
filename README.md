## Sobre o Projeto

Este é uma Single Page Application (SPA) construída com Laravel, Inertia.js e Vue.js. A aplicação combina a robustez do backend Laravel com a experiência moderna de uma aplicação frontend Vue.js, proporcionando uma experiência de usuário fluida e responsiva.

### Tecnologias Utilizadas

- **Laravel** - Framework PHP moderno e expressivo
- **Inertia.js** - Conecta o backend Laravel com o frontend Vue.js sem API
- **Vue.js 3** - Framework JavaScript progressivo
- **Laravel Jetstream** - Autenticação e gerenciamento de usuários
- **Tailwind CSS** - Framework CSS utilitário
- **Laravel Sanctum** - Autenticação API para SPAs
